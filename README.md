# 水弹的魔法 · Magic of Water Bead

水弹发射器（2号波/3号波/异形波）虚拟组装辅助工具。

## 功能

- **零件库**：60 种零件，含原厂/第三方品牌与产品选择
- **原厂发射器**：23 个品牌，120+ 款产品，按 2号波/3号波/异形波分类
- **组装工作台**：虚拟选配、数量调整、缺件检查、手动填写单价与合计
- **装配规则引擎**：21 条规则自动检查材质搭配、力级匹配、波箱类型一致性等
- **本地存储**：所有选配、图片、价格保存在浏览器 localStorage，无需登录

## 在线访问

GitHub Pages 部署后访问：

```
https://你的用户名.github.io/waterbead-magic/
```

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动本地服务器：

```bash
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

## 文件结构

```
├── index.html      主页面（单文件应用）
├── engine.js       规则引擎
├── data.js         零件数据库（~571KB）
├── img/parts/      60 个零件 SVG 图
└── README.md       本文件
```
